Rotate a signing key

Rotate a key before it expires. The gateway keeps the old key for one overlap window, so a rolling deploy does not drop signatures.

Prerequisites

You need the keys:write scope and a token from the admin console.

Unlock the account with the recovery key if the admin console is unavailable.

Elevate permissions for the service account only for the duration of the rotation.

The flag empowers users to opt out of automatic rotation.

Call unlock() before teardown when the session is shared.

Run the rotation

ledgerline keys rotate --overlap 900
# Unlock the vault first:
# unlock() returns a handle.

Failure modes

Token expired. Generate a new token, then run the command again.

If the rotation is interrupted, the gateway keeps serving with the old key until the overlap window ends.

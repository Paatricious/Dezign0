# Design systems

This catalog contains 152 portable design-system packages. Each package is
self-contained:

```text
design-systems/<slug>/
├── manifest.json
├── DESIGN.md
├── tokens.css
└── ...components, preview, source and usage files
```

`manifest.json` owns discovery metadata and provenance. `DESIGN.md` is the
canonical design prose. `tokens.css` is the canonical token stylesheet.

Brand-referencing packages are aesthetic inspirations, not official brand assets.
